# Générateur de site web Discord / Minecraft

Application web permettant de créer un site vitrine personnalisé pour un
serveur Discord et/ou Minecraft : aperçu en temps réel (desktop / tablette /
mobile), récupération automatique des infos publiques via les API Discord et
Minecraft, cartes d'avantages personnalisables, et export en un fichier HTML
autonome.

100% statique — aucun backend, aucune installation, aucun build requis.
